## 📌 About

A simple, clean, single-page portfolio built with plain HTML, CSS and JavaScript (no frameworks). It works on desktop, tablet and mobile.

## 🗂️ Project Structure

```
portfolio1/
├── index.html          # All page content
├── style.css           # Main styles
├── mediaqueries.css    # Mobile and tablet layout
├── script.js           # Hamburger menu toggle
├── favicon.ico
└── assets/             # Images, icons and resume.pdf
```

## 💻 Run Locally

No install or build needed.

```bash
git clone https://github.com/sikta-roy/portfolio1.git
cd portfolio1
```

Then open `index.html` in your browser.

## ✏️ How to Update

- **Text or projects:** edit `index.html`
- **Resume:** replace `assets/resume.pdf` (keep the same name)
- **Project image:** add a square image (1080×1080 works best) to `assets/` and update its `src` in `index.html`

Every push to `main` deploys automatically on Vercel.
